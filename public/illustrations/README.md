# Protected Journey Assets

Esta pasta contém todos os assets da animação principal da Home do Caminho Seguro.

## source

Arquivos originais baixados da internet.

Nunca editar.

Servem apenas como backup.

## optimized

Arquivos preparados pelo projeto.

Estes arquivos podem sofrer:

- otimização
- remoção de camadas
- alteração de cores
- padronização
- separação de grupos
- limpeza de metadata

Os componentes React devem utilizar somente os assets desta pasta.

Nunca utilizar diretamente os arquivos de source.
